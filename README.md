# Expense Tracker

A command-line application built with Python that helps users record daily expenses and understand where their money goes.

## Features
- Add expenses with category, description, amount, and date
- View all expenses in a table with the total
- Spending summary by category with percentages
- Monthly report with total, average, and biggest expense
- Input validation for amounts and dates
- Data saved permanently in a CSV file

## Technologies
Python, csv, datetime, collections

## How to run
1. Install Python 3
2. Download expense_tracker.py
3. Run: python expense_tracker.py
